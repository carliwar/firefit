# FireFit

Plan personal de entrenamiento y nutrición, publicado como sitio estático en GitHub Pages.

## Publicación

Cada push a `main` ejecuta el workflow de GitHub Actions y publica únicamente el HTML del plan como `index.html`. El README y los archivos de configuración permanecen en el repositorio, pero no se incluyen en el artefacto publicado.

Sitio: https://carliwar.github.io/firefit/

Para volver a desplegar manualmente, ejecuta el workflow **Deploy to GitHub Pages** desde la pestaña **Actions** del repositorio.
